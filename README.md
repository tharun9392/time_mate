# TimeMate 🕰️

**TimeMate** is a premium, modern companionship service platform built on the MERN stack. It provides a secure, intuitive booking system for users to hire time and companionship for various platonic activities such as city walks, coffee dates, and events.

## 🚀 Key Features
- **Premium Aesthetics**: Fully responsive UI designed with a clean, modern Indigo & Slate theme utilizing ultra-smooth glassmorphism overlays.
- **Dynamic Bookings**: Integrated multi-step form allowing users to pick specific activities, duration, date, time, and conversation preferences.
- **Live Location API**: One-click geolocation fetching to pinpoint exact meeting spots seamlessly via Google Maps integration.
- **Direct Communication**: Bookings are parsed transparently into formatted WhatsApp messages, immediately connecting clients and the companion.
- **Safety First**: Clearly delineated boundaries, transparent cancellation policies, and explicit consent checkboxes before generating any booking.

## 🛠️ Technology Stack
- **Frontend**: React (via Vite), React Router DOM, Lucide-React Icons, Vanilla Custom CSS
- **Backend Infrastructure**: Node.js, Express.js
- **Database**: MongoDB (via Mongoose)

## 💻 Running Locally

### Frontend
```bash
cd client
npm install
npm run dev
```

### Backend
```bash
cd server
npm install
npm run dev
```
